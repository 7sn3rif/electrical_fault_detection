This repository focuses on electrical fault detection and classification in a three-phase power system using machine learning. Built from the Kaggle dataset “Electrical Fault Detection and Classification,” the project trains a Random Forest model to identify fault conditions such as line-to-ground, line-to-line, double line-to-ground, and three-phase faults based on phase current and voltage signals. A Flask web application provides an interactive interface for real-time fault prediction and visualization.
